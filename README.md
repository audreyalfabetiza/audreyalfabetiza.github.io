# Site Audrey Americano

Site estático (Eleventy), publicado no GitHub Pages por GitHub Actions. Painel de postagens: Pages CMS (`.pages.yml`).

- Local: `npm install` e `npm start`
- Build: `npm run build` (gera `_site`)
- Textos: `src/conteudos/` · Fotos: `src/uploads/`
- Endereço final do site: variável `SITE_URL` (Settings > Secrets and variables > Actions > Variables)
