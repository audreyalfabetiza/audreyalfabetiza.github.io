# Site Audrey Americano

Site estático (Eleventy) com painel de postagens (Decap CMS), pronto para o Netlify.

- Desenvolvimento: `npm install` e `npm start`
- Publicação: `npm run build` (pasta `_site`)
- Painel da Audrey: `/admin/`
- Variável no Netlify: `SITE_URL` = endereço final do site (ex.: `https://www.seudominio.com.br`)
- Textos novos ficam em `src/conteudos/`, fotos em `src/uploads/`.
